## 三、Shell
1. **即命令解释器**：程序解析，执行或调用程序执行。
2. **特点**：无图形操作界面（GUI），使用命令行界面（CLI）。
3. **命令的基础结构**：`命令名称 [选项] [参数]`
4. **基础操作**：
   - `TAB` 补全（命令名称，文件路径）。
   - 光标导航：`Home` 行首，`End` 行末，`Ctrl + ←` 左移一个单词。
   - `Ctrl + Insert` 复制，`Shift + Insert` 粘贴。
5. **获取命令的文档**：
   - `命令 --help`（如 `ls --help`）
   - `man [命令]`（如 `man ls`，获取详细手册）
6. **路径的写法**：
   - **绝对路径**：从 `/` 开头。
   - **相对路径**：
     - `..` 上一层
     - `.` 当前
     - `~` 家目录
7. **基础命令**：
   - `pwd`：显示当前路径。
   - `ls`：列出目录内容。
   - `mkdir -p`：创建目录，可递归创建父目录。
   - `touch`：创建新文件或更新时间戳。
   - `cp`：复制文件或目录。
   - `mv`：移动或重命名。
   - `cat` / `less`：查看文件内容（`less` 适合分页查看大文件）。
8. **四种常用组合**：
   - **变量**：`$` 表示拿出来用（如 `echo $name`）。
   - **重定向**：
     - `>` 清空覆盖
     - `>>` 在末尾追加
   - **管道 `|`**：上一个命令的输出，作为下一个命令的输入。
   - **条件连接**：
     - `&&` 成功则运行
     - `||` 失败则运行
     - `;` 总之都要运行

## 四、Vim
1. **四个模式**：
   - **普通模式（Esc）**：移动光标，删除、复制、粘贴。
   - **插入模式（i）**：打字输入。
   - **命令模式（:）**：保存退出，搜索替换。
   - **可视模式（v）**：选中文本。
2. **退出命令**：
   - `:w` 保存
   - `:q` 退出
   - `:q!` 强制退出不保存
   - `:wq` 保存并退出

## 五、Git 与 GitHub
1. **四个位置流转**：
   工作区 `add` (编辑) -> 暂存区 `commit` (本次提交) -> 本地仓库 `push` (历史提交记录) -> 远程仓库。

2. **Git 常用命令表**：

| 命令 | 作用说明 |
| :--- | :--- |
| `git clone <仓库地址>` | 把云端整个代码库完整下载到本地 |
| `git status` | 检查当前哪些文件被改动或未追踪 |
| `git diff` | 对比并显示还没暂存的具体代码改动 |
| `git log --oneline` | 单行精简版查看过去的提交 |
| `git switch -c feature/hello` | 新建一个分支并立刻跳转过去 |
| `git add hello.txt` | 把指定文件的改动放入暂存区 |
| `git commit -m "Add greeting"` | 把暂存区的改动打包并附言保存 |
| `git push -u origin feature/hello` | 把新分支推送到云端并绑定默认 |
| `git switch main` | 从当前分支切换回主干道 |
| `git pull` | 拉取云端最新代码并自动合并到本地 |
