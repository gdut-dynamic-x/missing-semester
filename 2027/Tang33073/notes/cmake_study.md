## 一、编译构建基础
### 1.1 源代码到可执行程序
计算机硬件只能识别由0和1组成的二进制机器码，我们编写的C/C++高级语言代码无法直接被硬件执行，必须经过编译器翻译转换，完整流程分为4个阶段：
1. **预处理**：处理头文件等
2. **编译**：高级语言代码翻译成汇编语言
3. **汇编**：将汇编语言转换为纯二进制机器指令
4. **链接**，生成最终可直接运行的可执行程序

## 二、CMake 知识点整理
### 2.1 CMake 的定位与核心优势
是构建系统的生成器
优势：
1. **跨平台通用**
2. **维护成本低**
3. **扩展性强**

### 2.2 CMake 基础语法（补充教程学习记录）
- `cmake_minimum_required`：指定支持的最低CMake版本，避免版本不兼容
- `project`：定义工程名称，同时自动设置内置变量
- `add_executable`：指定要生成的可执行文件，以及对应的源文件
- `include_directories`：添加头文件搜索路径，解决头文件找不到的报错
- `target_link_libraries`：为目标可执行文件链接依赖的第三方库
基础编译流程：
1. 在工程根目录编写`CMakeLists.txt`
2. 执行`cmake .`生成构建文件与Makefile
3. 执行`make`命令完成编译，生成可执行程序

### 3.2 Catkin 工作空间结构

| `src` | 源代码空间,手动修改的目录 |
| `build` | 编译中间空间，存放中间产物,无需手动修改 |
| `devel` | 开发空间，存放可执行文件、库文件与脚本 |

### 3.3 工作空间创建实操
完整创建与编译命令：
```bash
# 递归创建工作空间与src目录
mkdir -p catkin_ws/src

# 进入src目录
cd catkin_ws/src

# 初始化工作空间，生成顶层CMakeLists.txt
catkin_init_workspace

# 返回工作空间根目录
cd ..

# 编译整个工作空间
catkin build
