# 培训课第一课作业要求

**注意：任务的完成需要按照工作流规范来完成，工作流规范详见培训课PPT**
1. 创建你自己的开发分支，以自己的github用户名在`2027`文件夹里面创建你自己的文件夹，你的内容都将会放到这个文件夹里面
2. 创建文件夹notes，在里面创建一个.md文档，要求使用英文命名，正确合理地使用Markdown语法写一份关于培训课第一课内容的笔记（Linux、Vim && Shell、Git && GitHub）
3. 创建文件夹homework，在里面写一个.sh脚本，要求运行脚本后输出：运行脚本时的系统时间、最近使用的10条命令、你的笔记的字数，**重定向**到同路径下的`output.txt`
4. 最后提交并push到你的远程，并向目标仓库open一个PR，commit消息注意英文大写开头带句号，PR标题英文注意大写开头，PR描述可以使用中文但是要描述清晰你的PR提交了什么东西
5. 定期关注你的PR的comments，有严重问题的PR我会在comments里面评论你的问题，你需要修改并重新PR
6. 该任务的ddl为10月20日23:59，在此之前成功PR即可，我们会对你们的作业进行第一阶段审核，暂时不用担心是否被Merge
7. 你的文件夹后续还将会继续被使用，notes用于存放笔记，homework用于存放作业内容
8. 后续课程可能继续使用该仓库提交作业，所以本文件`TASK.md`会更新，你们的PR可能会出现Conflict，需要你们正确处理冲突
9. **注意：即使已经开了PR也是可以修改PR的标题、描述、PR分支等等信息与内容，以及你的新提交会自动更新到PR，所以不要自己Close PR，一定要正确处理PR的不规范以及Conflict，发现通过Close PR再重新PR的方法来规避Conflict的会对本节课作业扣分**
